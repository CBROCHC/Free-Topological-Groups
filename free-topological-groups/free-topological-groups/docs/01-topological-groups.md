# 1 · Topological groups

[← Back to README](../README.md) · Next: [Free groups →](02-free-groups.md)
*Thesis: Chapter 2, pp. 11–28.*

A **topological group** is a group whose topology is compatible with the group operations. This chapter collects the tools used later: neighbourhood calculus, quotients, topological isomorphisms and initial topologies.

---

## Definition

> **Definition 2.1.** Let $G$ be a group and $\tau$ a topology on $G$. Then $(G,\cdot,\tau)$ is a **topological group** if multiplication $m(g,h)=gh$ is continuous $G\times G\to G$ (product topology) and inversion $i(g)=g^{-1}$ is continuous $G\to G$.

Equivalently, the single map $\varphi(g,h)=gh^{-1}$ is continuous.

**Examples**

| Example | Why it works |
|---|---|
| $(\mathbb R^n,+)$ with the usual topology | addition and negation are continuous |
| The circle group $\mathbb T=\{z\in\mathbb C : \lvert z\rvert=1\}$ | product and inverse of unimodular complex numbers are continuous |
| Any group with the **discrete** topology | every map out of a discrete space is continuous |

## Structure: what the topology looks like

| Result | Statement | Why it matters |
|---|---|---|
| **Prop 2.2** | Translations $x\mapsto xg$ and $x\mapsto gx$ are homeomorphisms; if $\mathcal B_e$ is a local base at $e$, then $\{Ug : U\in\mathcal B_e\}$ is a local base at $g$. | The topology is determined by what happens at the identity. |
| **Thm 2.1** | For a local base $\mathcal U$ at $e$ and $U\in\mathcal U$ there are $V\in\mathcal U$ with $V^2\subseteq U$, with $V^{-1}\subseteq U$, with $xVx^{-1}\subseteq U$ …; and there is a base of **symmetric** neighbourhoods. | "Neighbourhood calculus" used throughout. |
| **Prop 2.4** | If $A$ is open, then $AB$ and $BA$ are open for every $B\subseteq G$. | Open sets stay open under products. |
| **Prop 2.3** | A homomorphism between topological groups that is continuous at $e$ is continuous everywhere. | Continuity checks reduce to the identity. |
| **Cor 2.3** | A subgroup containing a non-empty open set is open. | |
| **Cor 2.4** | **Every open subgroup is also closed.** | Its cosets are open and partition $G$, so the complement of a coset is open. Key ingredient of [Cor 4.2](05-open-subgroups.md). |
| **Prop 2.5** | The closure of a subgroup is a subgroup. | |

## Quotients

Let $H \trianglelefteq G$ be normal, with $G/H$ carrying the quotient topology induced by $\pi:G\to G/H$.

* **Lemma 2.1.** $\pi$ is an **open** map. (Because $\pi^{-1}(\pi(U)) = UH$ is open.)
* **Lemma 2.2.** $G/H$ is Hausdorff $\iff$ $G/H$ is $T_1$ $\iff$ $H$ is **closed**.
* **Theorem 2.2.** If $H$ is normal **and closed**, then $G/H$ is a (Hausdorff) topological group.

> **Proof idea.** To show $m_c$ and $i_c$ continuous on $G/H$, use that $\pi\times\pi$ is a quotient map, so it suffices to check $m_c\circ(\pi\times\pi)=\pi\circ m$ and $i_c\circ\pi=\pi\circ i$, both continuous.

## Topological isomorphisms

> **Definition 2.3.** A homomorphism $f:G\to H$ is a **topological isomorphism** if it is a group isomorphism *and* a homeomorphism. We write $G\cong H$.

Categorically, topological groups form a category whose morphisms are continuous homomorphisms; its isomorphisms are exactly the topological isomorphisms.

**Note 2.2 (transport of structure).** If $G$ is a topological group and $f:G\to H$ is a bijection onto a set $H$, there is a *unique* group structure and topology on $H$ making $f$ a topological isomorphism.

---

## Initial topology generated by homomorphisms

> **Definition 2.4.** Let $G$ be a group, $\{(G_i,\tau_i)\}_{i\in I}$ topological groups and $\varphi_i:G\to G_i$ homomorphisms. With the diagonal map $\Delta:G\to\prod_i G_i$, $\pi_i\circ\Delta=\varphi_i$, the **initial topology** $\tau$ on $G$ is the one with base $\{\Delta^{-1}(U) : U \text{ open in } \prod_i G_i\}$.

* **Prop 2.6.** $(G,\tau)$ **is a topological group**, and $\Delta$ is a continuous homomorphism.

This construction returns in [Section 4.2](04-free-topological-groups.md#from-the-universal-property-to-a-constructive-topology), where $G=F_a(X)$.

* **Prop 2.7.** Two continuous maps $f,g:X\to Y$ with $Y$ **Hausdorff** that agree on a dense subset $D\subseteq X$ agree everywhere. *(Used for uniqueness of $F(X)$.)*
